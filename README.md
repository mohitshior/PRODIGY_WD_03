# Tic-Tac-Toe Web Application — Prodigy Infotech Task-03

A responsive Tic-Tac-Toe web application made with **HTML, CSS and JavaScript**.

## Features
- Player vs Player mode
- Player vs AI mode
- Unbeatable AI using the Minimax algorithm
- X/O selection
- Win, draw and turn detection
- Scoreboard
- Reset button
- Responsive design for mobile and desktop
- No external libraries required

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html`.
4. Either:
   - double-click `index.html` to run it in a browser, or
   - use the **Live Server** extension and click **Open with Live Server**.

## Files
- `index.html` — page structure
- `style.css` — UI and responsive styling
- `script.js` — game logic and AI
- `README.md` — project documentation

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
